# 🎨 Super Arte - Tienda de Artículos de Arte

Una aplicación web moderna para **Super Arte**, tu tienda especializada en materiales y productos artísticos. Desarrollada con Next.js y diseñada con una interfaz atractiva y responsiva.

## 📋 Descripción

Super Arte es una tienda online que ofrece:
- **Materiales de pintura y dibujo** (óleos, acrílicos, acuarelas, lápices, carboncillos)
- **Productos para manualidades** (scrapbooking, decoración, bisutería)
- **Arte digital** (tabletas gráficas, stylus, software)
- **Kits completos** para principiantes y profesionales
- **Talleres grupales** y eventos corporativos
- **Asesoría técnica** personalizada

## 🚀 Tecnologías Utilizadas

- **Next.js 14** - Framework de React para producción
- **TypeScript** - Tipado estático para JavaScript
- **Tailwind CSS** - Framework de CSS utilitario
- **Radix UI** - Componentes de UI accesibles
- **Lucide React** - Iconos modernos
- **React Hook Form** - Manejo de formularios
- **Next Themes** - Soporte para temas
- **Shadcn/ui** - Sistema de componentes

## 📦 Instalación y Uso

### Prerrequisitos
- Node.js (versión 18 o superior)
- PNPM (recomendado) o npm

### Pasos para ejecutar el proyecto

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/Omardo01/super-arte-web
   cd super-arte-web
   ```

2. **Instalar dependencias**
   ```bash
   pnpm install
   ```

3. **Ejecutar en modo desarrollo**
   ```bash
   pnpm dev
   ```

4. **Abrir en el navegador**
   ```
   http://localhost:3000
   ```

### Otros comandos útiles

```bash
# Construir para producción
pnpm build

# Ejecutar en producción
pnpm start

# Verificar código (linting)
pnpm lint
```
